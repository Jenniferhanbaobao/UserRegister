# 实验2：HTML5进阶综合训练 —— 用户注册页面

## 一、作业内容
本实验为《Web应用开发技术实验》的第二次作业，核心任务是制作一个完整的“用户注册”页面。项目要求综合运用 HTML5 的列表、表格、表单三大模块知识，并遵循语义化标签规范与代码缩进标准。

### 主要功能与结构
- **页面整体结构**：使用 `<header>`、`<main>`、`<footer>` 语义化标签包裹页面头部、表单主体与底部版权信息，以 `<h1>` 作为主标题。
- **注册表单（核心）**：
  - 包含用户名、密码、确认密码、性别、出生日期、邮箱、手机号、兴趣爱好、头像上传、所在城市、个人简介等控件。
  - 运用多种 HTML5 新增类型（`date`、`email`、`tel`）及属性（`required`、`pattern`、`placeholder`）。
  - 展示 `<label>` 的两种用法（包裹式与 `for+id` 关联）。
  - 提供提交与重置按钮。
- **表格应用**：插入“注册须知”表格，使用 `<thead>`、`<tbody>` 划分区域，并运用 `colspan`/`rowspan` 合并单元格。
- **列表应用**：
  - 无序列表 `<ul>`：注册流程/注意事项。
  - 有序列表 `<ol>`：注册步骤说明。
  - 定义列表 `<dl>`：常见问题/术语解释。
- **数据验证**：使用 JavaScript 监听表单提交事件，在 Console 中打印收集到的数据，并通过 Chrome DevTools 进行 DOM 结构与数据校验。

## 二、使用到的标签
- **语义化结构**：`<header>`、`<main>`、`<footer>`、`<nav>`（可选）
- **表单相关**：`<form>`、`<input>`（含 `text`/`password`/`radio`/`checkbox`/`file`/`email`/`tel`/`date`/`submit`/`reset`）、`<label>`、`<select>`、`<option>`、`<textarea>`、`<button>`
- **表格相关**：`<table>`、`<thead>`、`<tbody>`、`<tr>`、`<th>`、`<td>`（含 `rowspan`、`colspan`）
- **列表相关**：`<ul>`、`<ol>`、`<li>`、`<dl>`、`<dt>`、`<dd>`
- **基础标签**：`<h1>`、`<p>` 等

## 三、遇到的困难及解决方法
1. **表单数据收集与验证**
   - **困难**：初次使用 JavaScript 监听表单提交时，页面会默认刷新导致无法在 Console 查看到打印数据；手机号的 `pattern` 正则校验不生效。
   - **解决方法**：在 JS 事件处理函数中添加 `e.preventDefault()` 阻止默认提交行为；调整 `pattern="[0-9]{11}"` 确保手机号格式校验，并通过 DevTools 的 Console 面板成功打印表单数据。
2. **表格单元格合并**
   - **困难**：在使用 `colspan` 和 `rowspan` 时，容易出现表格结构错乱或跨行/跨列计数不准确。
   - **解决方法**：参照教材 P189，先在纸上规划表格结构，明确表头与主体（`<thead>`/`<tbody>`），再逐步调试属性值。
3. **语义化标签布局**
   - **困难**：习惯使用无意义的 `<div>`，对语义化标签的划分边界不够清晰。
   - **解决方法**：按照实验要求，将页面明确划分为头部（`<header>`）、主体（`<main>`）和底部（`<footer>`），提升代码可读性。
4. **Git 提交规范**
   - **困难**：初次提交多个文件（register.html、style.css、README.md）时，commit 信息格式需严格对应。
   - **解决方法**：按照要求，最终 commit 信息设定为“第二次作业：用户注册页面”，并成功推送至 GitHub 远程仓库。

## 四、实验总结与心得体会
通过本次“HTML5进阶综合训练”，我系统掌握了列表、表格、表单的综合应用，尤其是 HTML5 新增的表单类型和验证属性（如 `required`、`pattern`）极大提升了前端开发效率。同时，养成使用语义化标签替代 `<div>` 的习惯，有助于构建更清晰的页面结构。在调试过程中，熟练运用了 Chrome DevTools 的 Elements 和 Console 面板，为后续复杂 Web 应用开发打下了坚实基础。建议后续实验可增加更多 CSS 样式美化与交互逻辑，使页面更贴近真实项目。
